# SoupAndSoupApp - Аналіз проекту та план покращень

## 📋 Загальний огляд

**SoupAndSoupApp** - це крос-платформний додаток для розробки рецептів косметичних продуктів (мило та парфуми) з використанням Avalonia UI та .NET 8.

### 🏗️ Архітектура
- **Багатошарова архітектура** з чітким розділенням відповідальностей
- **MVVM паттерн** з ReactiveUI
- **Repository Pattern** для доступу до даних
- **Dependency Injection** для управління залежностями

### 🎯 Призначення
- Управління рецептами косметичних продуктів
- Каталог інгредієнтів з цінами та характеристиками
- Розрахунки собівартості рецептів
- Управління зображеннями продуктів
- Підтримка Desktop, Browser та Android платформ

### 🛠️ Технологічний стек
- **Frontend**: Avalonia UI 11.3.1, ReactiveUI, Material Icons
- **Backend**: .NET 8.0, Entity Framework Core
- **Infrastructure**: Azure Blob Storage, SQLite
- **Платформи**: Desktop, Web Browser, Android
